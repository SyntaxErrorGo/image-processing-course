## 📌 О задании

Первое домашнее задание: чтение полутонового изображения, анализ гистограммы,
гамма-коррекция, оценка качества (MAE / SSIM), эквализация гистограммы,
статистическая цветокоррекция и пороговая обработка.

Исходные данные — радарный снимок `sar_1_gray.jpg`, 400×600, `uint8`
(`mean = 74.94`, `std = 43.66`).

## 🧮 Реализовано вручную

Библиотечные функции используются **только для сверки** результата.

| Функция | Что делает | Сверка |
|:--------|:-----------|:-------|
| `hist_gray` | гистограмма через `np.bincount` | `cv2.calcHist` — расхождение `0` |
| `make_gamma_lut` / `gamma_correction` | гамма-коррекция через LUT на 256 значений | `cv2.LUT` — расхождение `0` |
| `mae_my` | средняя абсолютная ошибка (MAE) | `cv2.norm(..., NORM_L1)` — расхождение `0` |
| `ssim_my` | SSIM, окно 7×7, несмещённые дисперсии | `skimage.metrics.structural_similarity`, Δ ≈ `8e-16` |
| `equalize_hist_my` | эквализация по кумулятивной гистограмме | `cv2.equalizeHist` — расхождение `0` |
| `statistical_correction` | приведение `mean`/`std` к статистике эталона | — |
| `threshold_binary_my` | бинарный порог | `cv2.THRESH_BINARY` — расхождение `0` |
| `otsu_threshold_my` | порог Оцу через межклассовую дисперсию | `cv2.THRESH_OTSU` — `T = 85` в обоих случаях |

## 📊 Основные численные результаты

**Гамма-коррекция и метрики качества**

| γ    | mean   | MAE    | max\|Δ\| | SSIM    |
|:----:|-------:|-------:|--------:|--------:|
| 0.30 | 167.82 |  92.88 |     107 | 0.6208  |
| 0.50 | 131.09 |  56.15 |      64 | 0.7855  |
| 0.75 |  98.25 |  23.31 |      27 | 0.9355  |
| 1.00 |  74.94 |   0.00 |       0 | 1.0000  |
| 1.50 |  45.69 |  29.25 |      38 | 0.8137  |
| 2.20 |  25.09 |  49.85 |      72 | 0.4445  |
| 3.00 |  14.21 |  60.73 |      98 | 0.2176  |

> Чем сильнее `γ` отличается от 1, тем выше MAE и ниже SSIM.
> MAE выражена в единицах яркости — это средний сдвиг пикселя по шкале `0..255`.

**Эквализация и статистическая цветокоррекция**

| Изображение              | mean   | std   |
|:-------------------------|-------:|------:|
| исходное                 |  74.94 | 43.66 |
| `eq_gray` (эквализация)  | 127.03 | 74.27 |
| статистическая коррекция | 123.59 | 65.27 |

> Статистическая коррекция — линейное преобразование: она воспроизводит яркость и контраст
> `eq_gray` (MAE между ними 13.54, SSIM 0.950), но **не** выравнивает форму гистограммы.
> Остаточная ошибка (`Δmean = 3.44`, `Δstd = 9.00`) возникает из-за того, что 5.42 % пикселей
> уходит в насыщение `0`/`255` при обрезке диапазона.

**Пороговая обработка**

* 5 режимов `cv2.threshold` × 5 порогов (50, 100, 128, 150, 200) — доля белых и изменённых пикселей;
* автоматический выбор порога: Оцу `T = 85` (35.00 % белого), треугольный метод `T = 7` (95.33 %);
* адаптивный порог `MEAN_C` / `GAUSSIAN_C`, `blockSize` ∈ {11, 21, 51}, `C` ∈ {2, 5, 10}:
  рост `C` снижает эффективный порог и увеличивает долю белого, рост `blockSize` приближает
  результат к глобальному порогу.
